# Synapse Pages

Synapse Pages is a modern web application that collects, formats, and displays content from various sources like YouTube videos, articles, and e-commerce products etc.,. It uses AI to format content and provides a smart search functionality.

---

## Features

- Display content as modern cards with image, title, description, price, and type badge.
- Support for YouTube video embedding.
- Smart search powered by **Groq AI** that fetches the most relevant pages from the database.
- Easy-to-use REST APIs to save and fetch pages.
- Responsive and clean front-end UI using plain HTML, CSS, and JavaScript.

---

## Tech Stack

**Backend:**

- Node.js
- Express.js
- MongoDB (Mongoose)
- Groq AI / OpenAI for content formatting & search
- dotenv for environment variables

**Frontend:**

- HTML, CSS, JavaScript
- Responsive grid layout for modern card UI
